# 校巴数据需求与授权清单

## 权威来源

智慧珞珈是校巴业务数据的唯一权威来源。项目不得逆向接口、抓取受保护页面或从非授权副本导入真实用户/运营数据。

## 需要申请的数据

| 数据 | 最小字段 | 用途 | 敏感级别建议 |
|---|---|---|---|
| 站点 | 稳定 ID、名称、别名、位置、更新时间 | 站点检索 | 低敏感 |
| 线路 | 稳定 ID、名称、方向、途经站点、运营状态 | 线路查询 | 低敏感 |
| 班次 | 稳定 ID、线路 ID、发到站、发到时间、有效期、状态 | 班次和出行查询 | 低敏感 |
| 来源修订 | 版本、生成时间、有效期 | 审计、回滚、过期判断 | 低敏感 |

首期不申请用户身份、乘车记录、定位轨迹或车辆实时位置。实时位置和到站预测只有在校方明确授权并提供权威字段后单独评审。

## 需要校方确认

1. 正式数据负责人和审批人。
2. 授权接口、推送或文件交换方式。
3. 更新频率、最大允许延迟和服务时间。
4. 字段定义、稳定 ID 规则、时区和节假日表达。
5. 调用配额、网络白名单、凭据轮换与失效流程。
6. 数据保留周期、日志留存、备份和删除要求。
7. 测试环境、脱敏数据和生产数据的隔离规则。
8. 故障、错班次、数据泄露等事件的联系人与处理时限。

## 接入验收

- 接入适配器只能写 Go 托管统一存储。
- 每次导入使用事务，失败时保留上一完整修订版。
- 所有记录携带 `source_revision`，并保存导入时间、有效期和权威标记。
- 数据过期时 Capability 返回明确状态，不允许 Agent 推测或补造。
- 导入、查询和异常均携带 App、Echo/Task、来源修订及审计信息。

## 当前实现说明（2026-07-26）

统一存储已经实现原子快照激活、显式完整/权威/导入/有效期元数据、当前修订指针、并发一致读取以及稳定的新鲜度错误。未提供活动修订、元数据不完整、非权威或超过 `valid_until` 时不返回业务行。既有无法追溯证明完整的修订在迁移后默认不可用，必须重新导入。

这里的实现不代表真实数据接入已经获得授权。更新频率、最大允许延迟、正式来源标识和服务时间仍须由校方确认；在此之前，代码只执行来源给出的有效截止时间，不自行推断机构运营状态。
