# 武大校历场景设计

校历由 `calendar` Service 通过 `campus.calendar.events.list` Tool 查询，公开
Capability 为 `campus.calendar.events.list`（兼容别名 `campus.academic_calendar.query`）。
请求必须提供 UTC/RFC3339 `from`、`to`（最多 366 天）和可选 `limit`；响应携带
`data_status`、来源修订、导入时间和有效截止时间。

智慧珞珈是唯一权威来源。尚未取得书面授权时不接入真实数据；演示或非权威快照
必须显式标记，查询在 Go Tool 边界返回治理错误且不返回事件行。快照由 Go 管理的
SQLite 存储原子替换，按 `app_id` 隔离，事件必须引用同一来源修订并满足时间一致性。
