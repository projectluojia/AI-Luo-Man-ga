## 使用与更新

项目 README 可将本页作为统一的“版本沿革与贡献来源”入口。申报或审阅时，引用本页核验日期及相关固定 SHA；需要内部材料时，经授权另行提供，不把受限档案转成公开链接。

新增记录沿用“版本／工作事项／参与账号与角色／PR 或固定 SHA／测试或验收证据／确认状态”的简短结构。评审修复、迁移与原始实现分别说明，重排提交或迁仓后保留旧来源。更新分支状态时重新核实是否合并、原始 SHA 是否可达，不用提交数量替代实质贡献判断。

本页条目仍需相关参与者逐项核对各自记录与披露范围，未经确认的归属继续标明待核；作品署名、权属和成果认定则按各自适用程序确认。
